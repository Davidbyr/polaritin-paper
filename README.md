# Polaritin (极解素): 绕开基因突变的癌症生物电治疗新范式

## 一句话
不盯着癌细胞里成千上万的基因突变，而是抓住所有癌细胞共有的一个生物物理特征——**膜去极化**——来精准杀癌。

---

## 为什么要做这件事

现有靶向药的根本困境：

- 每个患者的基因突变组合都不一样，一种药往往只对一小部分人有效
- 癌细胞会不断突变，产生耐药性，治疗几年后失效
- 正常细胞和癌细胞共享很多靶点，药物副作用大

这条路换个思路：**不管癌细胞怎么突变，它们都逃不过一个共同的生理特征——膜电位去极化。**

---

## 核心发现

| | 正常分化细胞 | 癌细胞 |
|---|---|---|
| **静息膜电位 (Vm)** | −60 ~ −90 mV | −10 ~ −50 mV |

这个去极化是几乎所有类型癌细胞的统一生物电标志，从 1930 年代 Burr 的先驱观察到今天，已在肺癌、乳腺癌、结肠癌、黑色素瘤等数十种癌型中被反复验证。

更关键的是：它不是伴随现象，而是**主动驱动**癌症表型的——去极化促进细胞周期推进、抑制分化、增强侵袭能力；实验上把膜电位重新极化回正常水平，恶性表型就会逆转。

---

## Polaritin（极解素）是什么

一个**双门控（AND-logic）**电压门控钾通道（Kv）调节剂概念设计：

- **门控 1：电压门** — 只在去极化的癌细胞膜电位下才会构象开放（靠工程化的电压敏感结构域 VSD）
- **门控 2：化学门** — 需要外源性小分子配体结合才会真正激活离子通道

两个条件**同时满足**才会"开门"：

- 正常细胞膜电位太负 → 门不开
- 没有药物配体 → 门也不开

理论上实现：**只杀癌细胞，不伤正常细胞**，而且这个选择性锚定在电压阈值这种生物物理参数上，不依赖会不断突变的分子靶点。

## 为什么这条路重要

这是一条"降维打击"的思路：

1. **不跟基因突变赛跑** — 突变太多、太快，靶向药永远追不上
2. **靶向一个所有癌细胞共有的生物物理特征** — 不管突变怎么变，膜去极化这个表型逃不掉
3. **选择性来自物理参数** — 电压阈值是生物物理属性，不像蛋白靶点那样容易突变逃逸

如果这条路走通，理论上可以用一套药物框架覆盖异质性极高的肿瘤，而不是每出现一种新突变就重新设计一种药。
